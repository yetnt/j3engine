# About

J3Engine (or J3D) is a 3D graphics scene viewer which allows you to comfortably
view and manage a scene of objects without an amazing GPU.

---

Made completely in Java only using it's 
[2D Swing Graphics](https://docs.oracle.com/en/java/javase/21/docs/api/java.desktop/javax/swing/package-summary.html)
 to draw everything purely on the CPU. Custom Vector3, Matrix, Camera, SceneManager,
and many more classes.
